## Tools

| Tool                                                                                   | Description                                            |
| -------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| [Sonic Visualiser](https://sonicvisualiser.org/index.html)      | Audio waveform and spectrogram analysis tool           |
| [Audacity](https://www.audacityteam.org/)                       | Open-source audio editor and signal analyzer           |
| [Deep Sound](https://github.com/Jpinsoft/DeepSound)             | Audio steganography tool for hiding files in sound     |
| [XXY OSCILLOSCOPE](https://dood.al/oscilloscope/)               | Browser-based stereo waveform and oscilloscope viewer  |
| [Universal Radio Hacker](https://github.com/jopohl/urh)         | RF signal analysis and wireless protocol toolkit       |
| [GNU Radio](https://wiki.gnuradio.org/index.php/InstallingGR)   | SDR framework for signal processing and radio analysis |
| [Inspectrum](https://github.com/miek/inspectrum)                | Visual inspection tool for RF and digital signals      |
| [Detect DTMF Tones](http://dialabc.com/sound/detect/index.html) | Online decoder for telephone DTMF tones                |
