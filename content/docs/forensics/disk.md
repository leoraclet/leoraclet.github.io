## Tools

| Tool                                                                        | Description                                                 |
| --------------------------------------------------------------------------- | ----------------------------------------------------------- |
| [TestDisk](https://www.cgsecurity.org/wiki/TestDisk) | Disk recovery tool for lost partitions and boot sectors     |
| [PhotoRec](https://www.cgsecurity.org/wiki/PhotoRec) | File recovery tool that restores deleted files by signature |
| [Foremost](https://github.com/korczis/foremost)      | File carving tool for recovering data from disk images      |
| [Autopsy](https://www.autopsy.com/download/)         | Digital forensics platform for disk and case analysis       |
| └── [The Sleuth Kit](https://sleuthkit.org)          | Underlying forensic toolkit used by Autopsy                 |
