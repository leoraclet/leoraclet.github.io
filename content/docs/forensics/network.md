## Tools

| Tool                                                                               | Description                                                     |
| ---------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| [Wireshark](https://www.wireshark.org/)                     | GUI network protocol analyzer for packet capture and inspection |
| └── [tshark](https://tshark.dev/)                           | Command-line version of Wireshark for packet analysis           |
| └── [pyshark](https://github.com/KimiNewt/pyshark/)         | Python wrapper for tshark to automate packet analysis           |
| [NetworkMiner](https://www.netresec.com/?page=NetworkMiner) | Network forensic analysis tool for parsing captured traffic     |
