[AutoIt](https://www.autoitscript.com/site/autoit/) is scripting language for Windows.

## Tools

| Tool                                                                                                                                           | Description                                                        |
| ---------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| [Universal AutoIT Extractor and De-obfuscator](https://github.com/Wilenty/Universal-AutoIT-Extractor-and-De-obfuscator) | Extracts and deobfuscates AutoIt scripts from compiled executables |
| [AutoIt-Ripper](https://github.com/nazywam/AutoIt-Ripper)                                                               | Extracts embedded AutoIt scripts from PE binaries                  |
