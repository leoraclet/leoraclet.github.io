## Tools

| Tool                                                                                                                 | Description                                          |
| -------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| [PEiD](https://www.aldeid.com/wiki/PEiD)                                                      | Detects packers, cryptors, and compilers in PE files |
| [PE Bear](https://github.com/hasherezade/pe-bear)                                             | GUI tool for inspecting Portable Executable files    |
| [Process Explorer](https://learn.microsoft.com/en-us/sysinternals/downloads/process-explorer) | Advanced Windows process and DLL monitoring tool     |
| [Process Monitor](https://learn.microsoft.com/en-us/sysinternals/downloads/process-monitor)   | Real-time file system, registry, and process monitor |
| [TCPView](https://learn.microsoft.com/en-us/sysinternals/downloads/tcpview)                   | Displays active TCP/UDP network connections          |
| [System Informer](https://learn.microsoft.com/en-us/sysinternals/downloads/system-informer)   | Advanced system and process inspection utility       |
| [dnSpy](https://github.com/dnSpy/dnSpy)                                                       | .NET debugger and assembly editor/decompiler         |
| [ILSpy](https://github.com/icsharpcode/ILSpy)                                                 | Open-source .NET assembly decompiler                 |
| [dotPeek](https://www.jetbrains.com/decompiler/)                                              | JetBrains .NET decompiler and assembly browser       |
| [winchecksec](https://github.com/trailofbits/winchecksec)                                     | Checks Windows binaries for security mitigations     |
| [wine](https://www.winehq.org/)                                                               | Compatibility layer for running Windows apps on Unix |
| [winedbg](https://www.winehq.org/)                                                            | Debugger for Windows applications running under Wine |
