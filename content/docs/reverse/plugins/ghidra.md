| Tool                                                                                                | Description                                           |
| --------------------------------------------------------------------------------------------------- | ----------------------------------------------------- |

| [BTIGhidra](https://github.com/trailofbits/BTIGhidra)                        | Ghidra extension for binary type inference            |
| [Ghidra-evm](https://github.com/adelapie/ghidra-evm)                         | Ethereum Virtual Machine support for Ghidra           |
| [pwndra](https://github.com/0xb0bb/pwndra)                                   | Ghidra plugin suite for exploit development workflows |
| [SVD-Loader-Ghidra](https://github.com/leveldown-security/SVD-Loader-Ghidra) | Loads ARM CMSIS-SVD hardware descriptions into Ghidra |
