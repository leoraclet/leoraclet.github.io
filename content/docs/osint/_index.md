## Tools

| Category        | Tool Name | Description |
| :--------------- | :---- | :----------- |
| **General**       | [OSINT Framework](https://osintframework.com/) | A comprehensive framework for OSINT resources. |
| **Map**   | [Google Map](https://www.google.com/maps) | Interactive maps and satellite imagery. |
|                 | [OpenStreetMap](https://www.openstreetmap.org/) | Collaborative, open-source mapping platform. |
|                 | [Overpass Turbo](https://overpass-turbo.eu/) | Query tool for OpenStreetMap data. |
|                 | [World Imagery Wayback](https://livingatlas.arcgis.com/wayback/) | Historical satellite imagery archive. |
| **Image** | [Google Lens](https://lens.google/) | Image recognition and reverse image search. |
|                 | [TinEye](https://tineye.com/) | Reverse image search engine. |
| **Website** | [Wayback Machine](https://archive.org/web/) | Archive of historical web pages. |
| **Social Media** | [Check Usernames](https://checkusernames.com/) | Check username availability across platforms. |
| **Information** | [The Harvester](https://github.com/laramies/theHarvester) | E-mails, subdomains and names Harvester. |
|                 | [Moriarty](https://github.com/AzizKpln/Moriarty-Project) | Automated OSINT reconnaissance tool. |
|                 | [Trape](https://github.com/jofpin/trape) | People tracker on the Internet. |
