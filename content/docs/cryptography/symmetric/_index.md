[Symmetric key ciphers](https://en.wikipedia.org/wiki/Symmetric-key_algorithm) are ciphers that use the same cryptographic keys for both the encryption of plaintext and the decryption of ciphertext.

## Reference

Here is a list of the most common and often used symmetric key ciphers.

| Name | Key sizes (bits) | Type |
| :-- | :------ | :---- |
| [AES](https://en.wikipedia.org/wiki/Advanced_Encryption_Standard) | 128, 192, 256 | Block cipher |
| [DES](https://en.wikipedia.org/wiki/Data_Encryption_Standard) | 56 | Block cipher |
| [ChaCha20](https://en.wikipedia.org/wiki/Salsa20#ChaCha_variant) | 256 | Stream cipher |
| [Triple DES](https://en.wikipedia.org/wiki/Triple_DES) | 112, 168 | Block cipher |
| [RC4](https://en.wikipedia.org/wiki/RC4) | 40–128 bits | Stream cipher |
