[**ChaCha20-Poly1305**](https://en.wikipedia.org/wiki/ChaCha20-Poly1305) is an authenticated encryption with associated data (**AEAD**) algorithm, that combines the ChaCha20 stream cipher with the Poly1305 message authentication code.
