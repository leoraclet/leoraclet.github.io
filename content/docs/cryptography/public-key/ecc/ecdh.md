[**Elliptic-curve Diffie–Hellman**](https://en.wikipedia.org/wiki/Elliptic-curve_Diffie%E2%80%93Hellman) (ECDH) is a key agreement protocol that allows two parties, each having an elliptic-curve public–private key pair, to establish a shared secret over an insecure channel.

It is a variant of the [Diffie–Hellman](../../dhke) protocol using [elliptic-curve cryptography](../../ecc).
